# Deploying to Netlify

Since your project is not a git repository, the easiest way to publish it is using **Netlify Drop**.

1.  **Locate the Build Folder**:
    The production build is located at:
    `c:\Users\talsh\.gemini\antigravity\scratch\mortgage_calculator\dist`

2.  **Go to Netlify Drop**:
    Open your browser and go to [https://app.netlify.com/drop](https://app.netlify.com/drop).

3.  **Drag and Drop**:
    Drag the `dist` folder from your file explorer and drop it onto the area on the Netlify page that says "Drag and drop your site folder here".

4.  **Wait for Upload**:
    Netlify will upload your files and publish them instantly.

5.  **View Your Site**:
    Once uploaded, Netlify will give you a random URL (e.g., `agitated-babbage-12345.netlify.app`). You can click this link to view your live application on the internet!
